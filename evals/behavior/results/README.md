# Curated behavior-evaluation results

This directory is reserved for sanitized, reviewed summaries. It must not contain
raw prompts, copied instructions, stdout/stderr, diffs, worktrees, or local paths.
Use the ignored `artifacts/` or `local/` subdirectories for any local audit material.

The v0.1.0 release-candidate report records whether a behavior evaluation ran, its
scope, agent versions, validation status, and claim boundaries. It is deliberately
not a claim of universal behavioral equivalence.
