# `.glp` Specification

The formal `.glp` v0.1 specification now lives in [spec/glp-0.1.md](../spec/glp-0.1.md).

That spec defines:

- version headers
- allowed sections
- list and command syntax
- comments
- parsing errors
- compatibility expectations
- security considerations
- conformance examples

Use the files under [spec/fixtures](../spec/fixtures/) as parse and render conformance fixtures.

The versioned `.glp 0.2` expression and policy-link architecture is documented
in [`.glp 0.2` Policy Architecture](glp-0.2-policy-architecture.md). Version
0.2 adds structured predicate expressions, attached conditions/exceptions,
explicit `allow` semantics, and inseparable cross-modality policy linkage.
