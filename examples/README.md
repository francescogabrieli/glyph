# Glyph examples

Start with the [complete Claude Code compilation example](realistic-claude/README.md). It includes the original `CLAUDE.md`, the deterministic `.glp` output, reproducible commands, and an audit checklist.

Other directories demonstrate narrower features such as custom semantic rules, MCP configuration, and small backend workflows.

The examples are intended for inspection and reproducibility. They do not imply universal Markdown support, lossless arbitrary compression, or identical coding-agent behavior.
