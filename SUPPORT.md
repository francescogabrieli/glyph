# Support

## Where to start

- Installation or first manifest: [Getting started](docs/getting-started.md)
- CI, lockfile, or strict-mode question: [CI and lockfiles](docs/ci-cd.md)
- Parser or preservation question: [Troubleshooting](docs/troubleshooting.md)
- Format question: [`.glp` specification](docs/glp-spec.md)
- Custom repository convention: [Custom rules](docs/custom-rules.md)

## Good support requests

Include Glyph version, operating system, command, a minimal synthetic input,
and the expected safe outcome. Avoid posting credentials or proprietary source
instructions. For potential vulnerabilities, follow [SECURITY.md](SECURITY.md).
